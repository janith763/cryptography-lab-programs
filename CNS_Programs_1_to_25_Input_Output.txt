17. DES Decryption Key Schedule
Input:
Ciphertext block and DES key.
Output:
Decrypted plaintext block using subkeys K16 through K1 in reverse order.

18. DES Subkey Generation
Input:
64-bit DES key.
Output:
Sixteen 48-bit subkeys K1–K16, each formed from the appropriate 28-bit key halves.

19. CBC Encryption Using a Stronger Cipher
Input:
Plaintext blocks, encryption key, initialization vector (IV).
Output:
Ciphertext blocks produced using CBC mode with 3DES or another selected cipher.

20. Error Propagation in ECB and CBC
Input:
Plaintext blocks and ciphertext containing a bit error in a selected block.
Output:
ECB: only the corresponding plaintext block is corrupted.
CBC: the affected plaintext block and the following block are corrupted; later blocks are unaffected by a single ciphertext-block error.

21. Padding for ECB, CBC, and CFB
Input:
Plaintext and block/segment size.
Output:
Padded plaintext with a 1 bit followed by enough 0 bits to complete a block; an extra padding block is added when the original message is already block-aligned.

23. Counter Mode Encryption and Decryption
Input:

Initial counter: 00000000
Key: 0111111101

Output:
Ciphertext: 00111000 01001111 00110010

24. RSA Private-Key Calculation
Input:
Public exponent e = 31
Modulus n = 3599
Output:
Prime factors p and q; φ(n); private exponent d such that (31 × d) mod φ(n) = 1.

25. RSA and a Plaintext Block Sharing a Factor with n
Input:
RSA modulus n = p × q, public exponent e, and a plaintext block m with gcd(m, n) > 1.
Output:
The common factor gcd(m, n) reveals a nontrivial factor of n, which can compromise the RSA private key.
